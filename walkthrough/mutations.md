# Mutations, and what caught them

Recorded by `uv run python walkthrough/mutate.py`. Each row is a guard
that has been seen to fail: the change was applied, the named test went
red, and the file was put back. A guard nobody has broken is a guard
nobody has tested.

| Mutation | Caught by | What it would have hidden |
|---|---|---|
| the codec ignores its input | `tests/test_engine.py::test_text_survives_the_file` | Every WAV would be identical, so the determinism test would pass and the loop would close on the wrong words. |
| the codec stops being deterministic | `walkthrough/test_closed_loop.py::test_two_runs_produce_the_same_bytes` | The whole deterministic claim. A clock anywhere in the path and two runs stop agreeing. |
| the engine accepts audio it did not write | `tests/test_engine.py::test_it_refuses_audio_it_did_not_write` | A recording of a real voice would come back as whatever its samples spelled, answered 200, with nobody told. |
| the engine leaves its own directory | `tests/test_engine_contract.py::test_transcribe_refuses_to_leave_its_directory` | A real engine refuses a path escape. A stand-in that allows it passes a caller's traversal defect straight through to the real engine. |
| the engine stops saying what it is | `tests/test_engine_contract.py::test_it_says_what_it_is` | A caller could not tell the stand-in from a real engine somebody left running on the same workstation. |
| the client ignores its contract and hardcodes a path | `tests/test_contract.py::test_the_wire_used_this_contract_s_paths` | The whole agnosticism claim. A default that is the only value ever honoured is a hardcoding with a longer spelling, and everything still passes against the default engine. |
| the client ignores its contract and hardcodes a response key | `tests/test_contract.py::test_the_loop_closes_on_either_contract` | Same claim from the other side: reading a fixed key works against every engine that happens to spell it that way, and no others. |
| the engine answers a fixed path rather than its contract's | `tests/test_contract.py::test_the_loop_closes_on_either_contract` | The stand-in would only ever stand in for one engine, so a test claiming to exercise another would be exercising nothing. |
| the loop stops going over the wire | `walkthrough/test_closed_loop.py::test_it_went_over_the_wire` | `closed` would be True by construction. The loop would report success without ever reading back what it wrote. |
| speaking stops writing a file | `walkthrough/test_closed_loop.py::test_the_audio_is_a_real_file_written_this_run` | With a leftover file from a previous run the loop still closes. This is the stale-artifact hole, and it is why the walkthrough uses a fresh directory. |
| the synthesizer stops being deterministic | `tests/test_synth.py::test_the_same_text_gives_the_same_bytes` | An unseeded rng puts a clock in the fricatives, so the same words produce a different file every run and any recorded artifact churns. |
| the synthesizer ignores its input | `tests/test_synth.py::test_different_text_gives_different_bytes` | One sound for every phrase. The determinism test passes perfectly against it, which is why that test is not enough on its own. |
| the client drops the pause it was asked to send | `tests/test_stt.py::test_listen_sends_the_pause_when_the_contract_names_it_and_a_value_is_given` | A caller asking for a longer pause would get the engine's default and a sentence-length answer cut off mid-thought, with nothing failing. |
| the client sends the pause whether or not the contract names it | `tests/test_stt.py::test_listen_sends_no_pause_on_a_contract_without_one` | An engine with no such parameter would be sent one under a name it never agreed to, and the seam would hardcode a spelling. |
| the client drops the hint it was asked to send | `tests/test_contract.py::test_a_hint_travels_in_this_contract_s_spelling_or_not_at_all` | A short answer would be transcribed with no idea of the words it should be, and nothing would fail. |
| the client sends the hint whether or not the contract names it | `tests/test_contract.py::test_a_hint_travels_in_this_contract_s_spelling_or_not_at_all` | An engine with no such parameter would be sent one under a name it never agreed to. |
| an announcement drops the question's options | `tests/test_stt.py::test_announce_carries_a_question_s_options_in_the_order_given` | A display could no longer offer the answers as controls, so a person who cannot be heard has no other way to answer. |
| the SAPI path plays through pyttsx3's say | `tests/test_adapters.py::test_on_sapi_the_file_is_written_then_played_synchronously` | On Windows a sentence would be played through pyttsx3's say instead of SAPI's synchronous SpeakStream, and speak could return before it had been heard. |
| a named output that matches several is guessed | `tests/test_adapters.py::test_on_sapi_an_output_matching_several_or_none_is_refused` | A fragment naming several outputs would play to whichever came first, which can be a jack nobody hears. |
| a listen's confidence is read under a fixed name | `tests/test_contract.py::test_a_confidence_is_read_in_this_contract_s_spelling_or_not_at_all` | A caller deciding whether to ask for confirmation would read nothing from an engine that spells it differently, or something from one that never said. |
| the engine accepts a pause the engine it stands in for refuses | `tests/test_engine_contract.py::test_listen_refuses_a_silence_ms_joe_refuses` | A caller sending a pause outside the real engine's bounds would pass the offline suite and be answered 400 at the demo, which is the drift the stand-in exists to prevent. |
| the engine refuses the pauses at the edges of the bound it stands in for | `tests/test_engine_contract.py::test_listen_accepts_the_pauses_at_the_edges_of_joes_bound` | Every refusal case still passes against an exclusive bound; only a test sending the edges themselves tells an inclusive bound from one off by one. |
| every call builds its own client | `tests/test_stt.py::test_one_client_serves_every_call` | Nothing breaks: each call pays for a new client and its SSL context, and the loop slows with no other symptom. |
| a question is never cut short | `tests/test_adapters.py::test_on_sapi_a_sentence_stops_as_soon_as_until_says_so` | A person who answers before the question ends is talked over, and the answer waits for a voice that has stopped mattering. |
| a failing check stops the question | `tests/test_adapters.py::test_on_sapi_an_until_that_fails_never_cuts_the_sentence` | An engine that goes away mid-question would cut every question short, and the consent would never be heard in full. |
| an interruption is read under a fixed name | `tests/test_contract.py::test_an_interruption_is_read_in_this_contract_s_spelling_or_not_at_all` | An engine that spells it differently could never stop a question, however the person answered. |
| a watch is opened without the listen's parameters | `tests/test_stt.py::test_watch_posts_the_listen_s_parameters_briefly` | The take opened over the question would be transcribed without the answer's hint and ended on the engine's default pause. |
| an engine that cannot be asked is taken as an interruption | `tests/test_stt.py::test_interrupted_is_false_whenever_the_engine_cannot_say` | A question would be cut short on a guess whenever the engine stalled. |
| the media client asks a fixed transcribe route rather than its contract's | `tests/test_contract.py::test_the_media_wire_used_this_contract_s_spelling` | Every engine that spells its media surface differently would be asked for a route it does not have, and only the default's would ever answer. |
| a segment's time is read under a fixed key | `tests/test_contract.py::test_the_media_surface_answers_on_either_contract` | A transcript from an engine that times its segments under another name would be refused as malformed, and captions from it would never be made. |
| a refusal's reason is read under a fixed key | `tests/test_contract.py::test_a_refusal_s_reason_is_read_in_this_contract_s_spelling` | An engine that says why under another name would have its reason buried in its raw body. |
| a refusal is raised without the engine's reason | `tests/test_media.py::test_a_refusal_carries_the_engine_s_status_and_reason` | A person told a caption job failed would read 'Unsupported Media Type' and not which type, or what the engine takes. |
| a route the contract leaves out is asked anyway | `tests/test_media.py::test_a_route_the_contract_leaves_out_is_refused_by_name_before_any_request` | An engine with no such route would be sent the default engine's, and the failure would read as a malformed answer rather than a missing capability. |
| a language the engine cannot be asked for is dropped | `tests/test_media.py::test_a_language_is_refused_on_a_contract_that_cannot_ask_for_one` | A transcript would come back in whichever language the engine guessed, as if it were the one asked for. |
| words are asked for under a fixed name | `tests/test_media.py::test_words_travel_only_where_the_contract_names_the_parameter` | An engine with no such parameter would be sent one under a name it never agreed to. |
| a feature is asked for by vox's name rather than the engine's | `tests/test_media.py::test_a_feature_is_asked_for_by_the_engine_s_name_and_read_back_by_vox_s` | An engine whose name for a feature differs from vox's would refuse the analysis outright. |
| an upload's id goes into its route unescaped | `tests/test_media.py::test_an_id_is_escaped_whole_into_its_route` | An id with a separator or a query in it would address another route on the engine. |
| leaving the block leaves the uploads behind | `tests/test_media.py::test_leaving_the_block_discards_what_this_engine_still_holds` | Every caption job would leave its mixed sound on the engine until the engine's own clock took it. |
| a missing key in an answer is read as null | `tests/test_media.py::test_an_answer_that_is_not_the_contract_s_shape_is_malformed_and_says_where` | A contract spelling a key wrong would read as an engine with nothing to say, rather than as a mismatch to fix. |
| the stand-in answers the default media routes rather than its contract's | `tests/test_contract.py::test_the_media_surface_answers_on_either_contract` | The stand-in would stand in for one engine's media surface, so a test claiming to exercise another would exercise nothing. |
| the stand-in takes an upload of a type its engine refuses | `tests/test_engine_contract.py::test_a_media_upload_refuses_what_v1_refuses_with_a_detail` | A caller labelling its upload wrongly would pass the offline suite and be answered 415 by the real engine. |
| the stand-in hands an upload's id out twice | `tests/test_engine_contract.py::test_a_media_id_is_never_reused` | A caller holding a discarded upload's id would reach somebody else's upload with it. |
| an upload larger than the engine takes is sent anyway | `tests/test_media.py::test_an_upload_larger_than_the_engine_takes_is_not_sent` | An engine that judges the declared length can close the connection on a client still sending, and a too-large mix would read as an engine that is down. |
| the size limit is read under a fixed key | `tests/test_contract.py::test_an_upload_too_large_for_this_contract_s_engine_is_not_sent` | An engine stating its limit under another name would be sent uploads it refuses. |
| reaching the engine waits as long as its answer may | `tests/test_media.py::test_reaching_the_engine_is_bounded_apart_from_how_long_it_works` | An engine that is not there would hold a caption job for half an hour before anyone was told. |
| an analysis's tuning the contract cannot carry is dropped | `tests/test_media.py::test_a_tuning_the_contract_cannot_carry_is_refused_before_any_request` | A waveform asked for at a hundred values a second would come back at the engine's own rate, as if it were the one asked for. |
| the stand-in takes an analysis's tuning its engine refuses | `tests/test_engine_contract.py::test_a_media_analysis_holds_its_tuning_to_joe_s_bounds` | A caller asking for a peaks rate the real engine refuses would pass the offline suite and be answered 422 by the engine. |
| the stand-in reports a length it did not read from the upload | `walkthrough/test_media_engine.py::test_the_narration_goes_up_with_its_real_length` | Captions clamped to an upload's length would be clamped to a number the stand-in made up, and pass. |
| narration written by the platform voice is also played | `tests/test_adapters.py::test_on_sapi_to_wav_writes_the_file_and_plays_nothing_whatever_playback_says` | Making narration for a video would read every line aloud through the speakers of whoever made it. |
| narration is written to the synthesizer's own directory | `tests/test_tts.py::test_it_writes_the_wav_where_it_is_told_and_says_where` | A timeline would lay a path under its video that holds nothing, while the narration sat elsewhere under one fixed name. |
